Hello, I'm Brett. I am a software developer living in Philadelphia.

Professional experience

Since 2022, I have been a Senior Software Engineer for the City of Philadelphia. I was the lead backend developer on the following web apps:

lobbying.phila.gov
A public database of lobbying activity in Philadelphia in compliace with the City's Lobbying Law and enforced by its Board of Ethics. Released September 2026.

public-safety-reports.phila.gov
An online portal for requesting a digital copy of a crash or fire report from Philadelphia's Department of Records. Requires creating an account. Released January 2024.

Prior to working at the City I was a full-stack developer at The Vanguard Group in Malvern, PA.

Personal projects and demos

cool-relations.scm
One of my main interests in computing is relational programming in miniKanren. This commented Scheme source file contains the relations that I have been interested in since I was first introduced to miniKanren in 2019.

schreiberbrett.github.io/box-packing
Create arbitrary Tetris-like pieces using the grid of buttons and the "Add" button, then click the "Solve" button to find the smallest rectangle that fits all the pieces. Source code available at github.com/schreiberbrett/box-packing.

schreiberbrett.github.io/experiments/mindepth.html
A commented HTML file demonstrating that every predicate over unsigned integers can be represented as a NAND circuit. (Although finding such a circuit can be extremely inefficient!)

schreibebrett.github.io/translate-khmer
A web app for translating Khmer-language text, which often does not contain spaces. I made this for myself before learning that there is prior work on the Khmer word segmentation problem. Source code and a description of the greedy algorithm is hosted at github.com/schreiberbrett/translate-khmer.

nchlsb.github.io/early-calc
An interactive webpage I made with my friend Nick Brady for visualizing derivatives and integrals of common functions.

nchlsb.github.io/ChemicalEquationBalancer
Another joint project with Nick Brady. You are given a random chemical equation and must increment or decrement each coefficient until the equation is balanced. The type describing chemical formulas is recursive!
